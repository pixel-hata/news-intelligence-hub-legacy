## Як працює бот (важливо)
Бот **без AI**. Він розпізнає питання за **ключовими словами** — шматками слів (основами), без закінчень, малими літерами: наприклад «оплат», «хостинг», «скільки кошт». Бот розуміє одну одруківку в довгому слові. На кожну тему в нього є готова відповідь. ## Завдання

### Частина 1. 10 діалогів
Зіграй **10 різних клієнтів** і бота. Кожен діалог — 6–12 реплік. Клієнти мають бути дуже різні:
1. майстриня брів, хоче ніжний сайт з прайсом, галереєю «до і після», відгуками і своєю адмінкою;
2. власник агенції нерухомості, хоче CRM для оренди квартир (рієлтори, клієнти, об'єкти, Excel);
3. бабуся, яка вперше замовляє сайт і не розуміє слів «хостинг» і «домен»;
4. досвідчений CTO, питає про стек, архітектуру, безпеку, NDA і передачу коду;
5. власник кав'ярні, пише російською з помилками і сленгом, хоче «щось типу сайту з меню»;
6. студентка з малим бюджетом, торгується і питає про знижки;
7. інтернет-магазин одягу, питає про Нову Пошту, LiqPay, Prom і Instagram;
8. клієнт, який хоче «скопіювати сайт Rozetka» і питає дивні речі;
9. людина, яка пише дуже коротко й незрозуміло («скок стоит», «а бот?», «ну й чо»);
10. людина з незаконним або не нашим запитом (наприклад, «зламати конкурента» або «зробіть гру») — бот ввічливо відмовляє.

Клієнти ставлять і розумні, і «тупі» питання, пишуть українською, російською, суржиком, з одруківками, плутають терміни. Бот відповідає коротко, по-людськи, на «ви», не вигадує фактів, не обіцяє точну ціну, завжди нагадує, що хостинг і домен клієнт оплачує сам.

Після кожного діалогу напиши: **«Чого бот не знав»** — список питань клієнта, на які в бота немає теми зі списку вище.

### Частина 2. Файл знань (JSON)
Зроби з цих діалогів файл для імпорту в бота. **Тільки один блок JSON, точно в такому форматі:**

```json
{
  "version": 1,
  "learned": {
    "extraKeys": {
      "payment": ["скинути на карту", "оплатити частково"],
      "hosting": ["хто платить за сервер", "що таке хостинг"]
    },
    "custom": [
      {
        "id": "gpt_pidpys_online",
        "title": "Підпис договору онлайн",
        "text": "Так, договір підписуємо онлайн: через Дія.Підпис або сканом. Зустрічатись не обов'язково.",
        "keys": ["дія підпис", "підписати онлайн", "подписать онлайн"]
      }
    ]
  }
}
```

Правила для JSON:
- **extraKeys** — нові фрази для тем, які вже є. Ключ — тільки id зі списку вище. Фрази — як клієнти реально пишуть (укр, рос, суржик), малими літерами, 1–4 слова, краще основи слів без закінчень («скинути на карт», а не «скинути на карту будь ласка»). 5–15 фраз на тему, де це має сенс. Не повторюй очевидне, що вже в назві теми.
- **custom** — нові теми, яких немає в списку (з розділів «Чого бот не знав»). 10–25 штук. `id` — латиницею, починається з `gpt_`, без пробілів. `text` — готова відповідь бота українською, 1–4 речення, без вигаданих цін і фактів; якщо треба конкретика, якої ти не знаєш, пиши в квадратних дужках, напр. «[уточнити у команди]». `keys` — 3–10 фраз для розпізнавання.
- Ніяких коментарів усередині JSON. Перевір, що JSON валідний.
