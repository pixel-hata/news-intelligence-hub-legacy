## Як подивитись макет

Відкрийте `mockup/index.html` у Chrome, Edge або Firefox (подвійний клік).
Інтернет потрібен тільки для шрифтів — без нього сайт теж працює, але зі стандартним шрифтом.

Що перевірити:
1. **Головна** — живий 3D-блоб, рухайте мишкою.
2. **Розділи за ТЗ:** про нас, портфоліо з фільтром «Усі / ви / Діма», готові роботи, ціни, оцінка проєкту, IT-новини, стек і сервери, контакти.
3. **Бот** (розділ «05 // оцінка проєкту» або кнопка внизу праворуч):
   - кнопки меню: ціни, терміни, оплата, хостинг, портфоліо…;
   - «Порахувати вартість» → 11 типів проєктів → питання → розбивка, ціна, термін;
   - пишіть словами: «хочу CRM для агенції нерухомості», «а хто платить за домен?», «назад», «меню», «хочу поговорити з людиною»;
   - «Надіслати заявку» → форма → бот складає попереднє ТЗ.
4. **Заявки** — посилання «Заявки (для команди)» внизу сайту або `mockup/admin.html`: заявки, ТЗ, розмова, копіювання для Telegram, завантаження ТЗ (.md).

## Бот без AI

Бот не підключений до AI: він працює на кнопках і ключових словах, тож відповідає миттєво, безкоштовно і завжди однаково.
Усі гілки розмови описані в `docs/bot-scenarios.md`: 112 тем відповідей + словник із 48 термінів, 11 сценаріїв оцінки, заявка, звʼязок з людиною, відмова від незаконних задач. Бот розуміє укр/рос/англ, суржик, різні форми слів («записувались онлайн» = «запис онлайн») і одруківки. На «що таке бекенд / сервер / API…» пояснює простими словами, що це і навіщо саме клієнту.

Перевірено на 20 рольових клієнтах (майстер брів, агенція нерухомості, бабуся-новачок, CTO, кавʼярня, студентка, магазин одягу, «скопіюйте Розетку», лого для пекарні, ребрендинг, адаптація під телефон, редизайн, онлайн-школа, клініка, фотограф, подія, CRM для СТО, салону, доставки) — 111/111 питань і 62/62 питання «що таке…».

### Як бот вчиться сам

1. Кожне питання, яке бот не зрозумів, і кожне «Це не те, що я питав» записується.
2. Якщо після цього клієнт сам обрав тему, бот підказує: «мабуть, це про Оплату».
3. У `mockup/admin.html` → **«Навчання бота»** ви одним кліком додаєте фразу до готової відповіді або пишете нову — і бот одразу відповідає так усім.
4. Там само: перевірка будь-якої фрази («як бот це зрозуміє?») і файл знань, щоб передати Дімі або перенести на сервер.

Що більше клієнтів пишуть, то більше бот знає — без AI і без оплати за запити.

**Навчання через ChatGPT:** у `docs/prompt-for-chatgpt.md` готовий промпт — ChatGPT грає 10 різних клієнтів і бота, а в кінці дає JSON. Вставте його в `admin.html` → «Навчання бота» → «Додати з тексту».

**Ставка:** $10–15 за годину. Хостинг, домен і платні сервіси в суму не входять — бот завжди це пише.

### Що замінити в `mockup/js/bot-data.js`

У блоці `STUDIO` вгорі файлу:
- `telegram`, `email`, `phone` — ваші контакти;
- `prepay`, `designRevisions`, `bugfixDays`, `supportFrom` — ваші правила (зараз: 50% передоплата, 2 кола правок, 30 днів гарантії);
- `rateMin`, `rateMax` — ставка.

Також у тексті є заглушки в `[квадратних дужках]`: [ваше імʼя], способи оплати, ціна підтримки. Знайдіть їх пошуком `[`.

## Що зміниться на справжньому сайті

У макеті заявки зберігаються тільки в браузері, де їх залишили. На справжньому сайті сервер буде:
1. зберігати заявку в базу;
2. надсилати повідомлення у ваш спільний Telegram-канал (клієнт, сума, ТЗ файлом);
3. дублювати лист на пошту.

Для цього потрібні: токен Telegram-бота (від @BotFather), канал з ботом-адміністратором і адреса пошти.

## Що ще потрібно від вас

- Обрати лого (у макеті стоїть «Дуо»).
- Фото і тексти про себе, роботи для портфоліо, готові шаблони з цінами.
- Контакти і правила оплати/гарантії для бота.

## Як заявки приходять вам (Telegram + пошта)

Коли клієнт надсилає заявку в боті (або питання «Написати людині»), сайт відправляє її на сервер, а сервер — вам:
- **у Telegram** (спільний канал чи група): коротке повідомлення з клієнтом, контактом, ціною і терміном + **попереднє ТЗ файлом .md**;
- **на пошту**: те саме, ТЗ у вкладенні;
- і завжди зберігає копію в `server/data/leads.jsonl`.

Якщо відправка не вдалась, бот чесно каже клієнту написати вам напряму і показує контакти.

Запуск (потрібен Node.js 18+):

```bash
cd pixel-hub/server
cp .env.example .env      # впишіть токен бота, ID каналу, дані пошти
npm install               # потрібен для пошти
npm start                 # сайт на http://localhost:8080
```

Як отримати дані для `.env` — написано прямо у файлі `.env.example`. Файл `.env` з паролями не потрапляє в git.

Якщо відкрити `mockup/index.html` просто подвійним кліком (без сервера), заявки зберігаються тільки в браузері — їх видно в `admin.html`.

## Сторінки

1. **Головна** (`index.html`) — хто ми, портфоліо, готові роботи, ціни, бот з оцінкою, контакти.
2. **IT-новини** (`news.html`) — окрема сторінка про News Intelligence Hub: як працює, кластери тем (приклад), кнопка «Відкрити застосунок». Сам застосунок — окремий проєкт (код Діми), посилання на нього вставте замість `[посилання на News Hub]`.
