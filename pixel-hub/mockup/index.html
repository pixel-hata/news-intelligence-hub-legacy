Окремо платите провайдерам

Домен: .com.ua ≈ $8–12 на рік, .com ≈ $12–15 на рік. Хостинг: GitHub Pages / Netlify — $0; Firebase / Supabase — $0 на старті. Сервер для NovaCRM (VPS) ≈ $5–10 на місяць.

Умови

Як шаблон, без ексклюзиву — знижка до 30–50 %. Супровід після запуску — $20–50 на місяць. Навчання роботі з адмінкою — 1 год безкоштовно, далі $10/год. Передоплата 50 %, решта після запуску.

05 // оцінка проєкту

скільки коштуватиме ваш проєкт?

Наш бот-помічник поставить кілька питань і порахує попередню вартість і терміни. Або просто спитайте його про ціни, оплату, хостинг чи терміни.

  1. Обираєте тип проєкту або пишете своїми словами.
  2. Відповідаєте на 4–8 коротких питань кнопками.
  3. Отримуєте розбивку робіт, ціну і терміни.
  4. Надсилаєте заявку — ми пишемо з точною ціною і ТЗ.
